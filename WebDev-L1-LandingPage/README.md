# EcoLife Landing Page 

A simple and responsive landing page created using **HTML5 and CSS3**.

## About
EcoLife is a sustainable living webpage that provides information about eco-friendly habits and a greener lifestyle.

## Features
- Navigation Bar
- Hero Section
- Features Section
- About Section
- Testimonial Section
- Contact Section
- Footer
- Responsive Design

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
