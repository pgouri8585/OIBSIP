# Temperature Converter 

A simple and responsive temperature converter website created using HTML, CSS and JavaScript for my Oasis Infobyte Web Development Internship – Level 1 Task 3.

## Features
- Convert Celsius, Fahrenheit and Kelvin
- Input validation
- Absolute zero validation
- Error messages
- Displays all converted values
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript
